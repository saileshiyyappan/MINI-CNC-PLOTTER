## Overview

The Mini CNC Plotter is a completed educational embedded systems project developed in June 2019 to explore computer numerical control, stepper motor motion, firmware integration, and automated drawing.

The machine uses recycled DVD drive mechanisms to create two-axis movement, an Arduino-based controller to execute motion commands, and a servo motor to control pen movement. Digital artwork can be converted into G-code and sent to the machine to reproduce sketches, text, and simple graphics on paper.

The project provided practical experience in embedded programming, electronics integration, mechanical assembly, and digital fabrication.

## Problem Statement

Commercial CNC equipment can be expensive for beginners and educational environments. An accessible, compact platform can help learners understand motion control, G-code, stepper motors, and computer-controlled manufacturing through hands-on experimentation.

## Project Approach

The project combines repurposed mechanical components with an embedded motion-control system.

- **Motion system:** Recycled DVD drive mechanisms for two-axis movement.
- **Controller:** Arduino Uno-based control architecture.
- **Motor control:** Stepper motors with A4988 drivers.
- **Pen mechanism:** Servo-controlled pen lifting.
- **Firmware:** GRBL-based CNC control.
- **Drawing workflow:** Digital graphics converted into G-code and transmitted through USB serial communication.

- **June 2019 — Mechanical Assembly:** Constructed the two-axis mechanism using recycled DVD drives.
- **June 2019 — Electronics Integration:** Connected the Arduino controller, motor drivers, stepper motors, and servo.
- **June 2019 — Firmware Development:** Configured GRBL and established the G-code workflow.
- **June 2019 — Testing and Calibration:** Tested axis movement and drawing output.
- **June 2019 — Project Completion:** Completed the CNC plotter as an educational demonstration of embedded motion control and automated drawing.
